# Security

Report suspected vulnerabilities privately to mike@mikestaniforth.com. Do not include credentials, personal media or real customer data in public issues.

This edition is for local evaluation. It is not a supported production service. Use synthetic data. Cloud integrations require a separate security review, independent infrastructure and explicit configuration. Never expose a development server or a local rendering service to the public internet.

No production credentials or deployment workflow is supplied. Keep real environment files, local state, media, exports, service-account files and Terraform state out of Git. Review dependencies and scan the final tree before each release.
